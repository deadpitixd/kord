# Kord

Kord is a high-performance, statically-typed programming language made
from scratch in pure C.

Designed for speed and transparency of C, but with modern features,
Kord combines a minimalist, human-readable syntax with modern language ergonomics.

## Core Philosophy

* **Pure C:** Built entirely in ANSI C, keeping the runtime clean, embeddable, and transparent.
* **Strict Static Typing:** Catch type errors at compile time before a single line of code executes, with zero runtime type-tag overhead.
* **Clean Lexical Rules:** Unambiguous, elegant grammar that makes writing both manual parsers and reading source code effortless.
* **Zero Bloat:** Designed from day one to work both as a standalone compiled executable and as an embeddable scripting tool.
